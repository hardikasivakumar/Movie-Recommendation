# 🎬 Movie Recommendation System

An NLP-based movie recommendation system that uses **Word2Vec** and **Sentence Transformers** to recommend movies based on users' recently watched movies.

## 📌 Project Overview

The project aims to improve movie recommendations for an OTT platform by using users' recent viewing history and the semantic information available in movie metadata.

The system analyzes movie **titles, genres, and overviews** to generate embeddings and identify similar movies.

## 🎯 Objective

* Analyze users' recent movie-watching sequences.
* Build an AI-powered movie recommendation engine.
* Compare **Word2Vec** and **Sentence Transformer** approaches.
* Improve recommendation relevance and user engagement.

## 📊 Dataset

### Movie Dataset

* **4,803 movie records**
* 3 features:

  * `title` – Movie title
  * `genres` – Associated movie genres
  * `overview` – Movie plot description

Missing values were removed during preprocessing.

### Evaluation Dataset

* **2,000 records**
* `movie_1` to `movie_7` – Recently watched movies
* `movie_watch` – Movie actually watched
* `date` – Recommendation date
* `past_success` – Success of the previous recommendation model

## 🔧 Methodology

### 1. Text Preprocessing

Movie **title, genres, and overview** are combined to create a textual representation of each movie.

### 2. Word2Vec

Word2Vec is used to generate word-level embeddings. The embeddings of individual words are averaged to create a single vector representing each movie.

Movie similarity is calculated using **cosine similarity**.

### 3. Sentence Transformers

A pre-trained **Sentence Transformer** model is used to generate sentence-level embeddings that capture the contextual and semantic meaning of movie descriptions.

The embeddings are compared using **cosine similarity** to identify similar movies.

### 4. Recommendation

The embeddings of the user's recently watched movies are averaged to create a representation of their viewing preferences. Movies with the highest similarity scores are then recommended, excluding movies the user has already watched.

## 📈 Results

| Model                | Recommendation Success Rate |
| -------------------- | --------------------------: |
| Previous Model       |                  **13.85%** |
| Word2Vec             |                 **~17–27%** |
| Sentence Transformer |                  **64.75%** |

The **Sentence Transformer model significantly outperformed Word2Vec and the previous recommendation approach**, providing more relevant recommendations by capturing contextual and semantic relationships between movie descriptions.

## 🚀 Deployment

A simple interactive interface was created using **Gradio**, allowing users to select up to three movies and receive the top 10 recommendations generated by the Sentence Transformer model.
